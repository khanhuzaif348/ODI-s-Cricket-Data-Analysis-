# ESPN Cricket Performance Analytics Dashboard – Power BI
📌 Project Overview

This Power BI project focuses on analyzing ODI cricket player performance using data fetched from ESPN Cricinfo through Web API.
The purpose of this project is to clean, transform, and visualize cricket data to provide clear insights into Batting, Bowling, and Fielding performance.

The dashboard enables users to explore player statistics, understand performance patterns, and analyze their contributions across different skill areas.

⚙ Data Source

Platform: ESPN Cricinfo

Format: Web API Data Fetch

Data Type: ODI Player Statistics

Includes:

Batting Stats

Bowling Stats

Fielding Stats

🧹 Data Cleaning and Preparation

Performed essential data transformations including:

Removing duplicates and null records

Standardizing text formats

Extracting required metrics

Creating calculated measures

Separating Batting, Bowling, and Fielding tables

Converting columns into correct data types

Tools Used:

Power Query

DAX Measures

Power BI Desktop

📊 Dashboard Structure

The report is divided into three interactive dashboards:

Dashboard	Purpose
Batting Performance	Runs, Strike Rate, Average, Boundaries
Bowling Analysis	Wickets, Economy, Strike Rate, Best Figures
Fielding Insights	Catches, Stumpings, Dismissal Contribution


🚀 Key Features

✔ Player selection with dynamic visual updates
✔ Key Performance Indicators for quick insights
✔ Clean and simple UI for better readability
✔ Visual comparison between skill areas
✔ ODI-focused statistics to maintain consistency
